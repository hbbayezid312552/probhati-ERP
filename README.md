# প্রভাতী ইআরপি — Probhati ERP (Invoice, Sales, Stock & S.R Management System)

একটি সম্পূর্ণ Professional, Production-Ready, 100% Free & Open-Source Invoice, Sales, Stock, Dealer ও S.R (Sales Representative) Management Android & Web Application।

---

## 📌 ১. Project Description (প্রজেক্ট বিবরণ)

**Probhati ERP** খাদ্যপণ্য (FMCG) পরিবেশনকারী প্রতিষ্ঠান এবং ডিস্ট্রিবিউশন কোম্পানির জন্য বিশেষভাবে তৈরি একটি স্বয়ংক্রিয় এন্টারপ্রাইজ সিস্টেম। এই সিস্টেমে কোনো পেইড সফটওয়্যার, পেইড ডাটাবেজ (Paid Database), পেইড এপিআই (Paid API) বা পেইড হোস্টিং-এর প্রয়োজন নেই। সম্পূর্ণ সিস্টেমটি ডিভাইসের লোকাল স্টোরেজে অফলাইনে কাজ করে এবং একক ক্লিকে A4 সাইজের প্রফেশনাল ইনভয়েস প্রিন্ট বা PDF ডাউনলোড করা যায়।

### 🌟 প্রধান সুবিধাসমূহ (Key Features):
1. **Secure Admin Authentication**: SHA-256 এনক্রিপ্টেড পাসওয়ার্ড ভেরিফিকেশন। পাসওয়ার্ড সোর্স কোডে কখনো প্লেইন টেক্সট হিসেবে সংরক্ষিত থাকে না।
2. **Main KPI Dashboard**: আজকের সেলস, ইনভয়েস সংখ্যা, আজকের ড্যামেজ ও রিটার্ন, মোট কার্টুন ও পিস স্টক, স্বল্প স্টক অ্যালার্ট, ডিলার ও এস.আর সংখ্যা, মাসিক টার্গেট অগ্রগতি এবং ইন্টারঅ্যাক্টিভ চার্ট।
3. **Excel-Style Dealer Invoice**: কার্টুন, খুচরা পিস, Trade Price (T.P), % কমিশন এবং Dealer Price (D.P) স্বয়ংক্রিয় রিয়েল-টাইম ক্যালকুলেশন।
4. **S.R Sales & Damage/Return Invoice**: প্রতিটি আইটেমে বিক্রীত কার্টুন/পিস এর পাশাপাশি ড্যামেজ এবং রিটার্ন সংখ্যা আলাদাভাবে এন্ট্রি করার সুবিধা এবং নিট সেলস হিসাব।
5. **Atomic Stock Synchronization**: যেকোনো চালান এন্ট্রি, এডিট বা ডিলিট করলে কিংবা কারখানা থেকে পারচেজ (Purchase) এন্ট্রি করলে ইনভেন্টরি স্টক স্বয়ংক্রিয়ভাবে পুনঃহিসাব ও অ্যাডজাস্ট হয়।
6. **S.R Monthly Targets & Product Quota**: প্রতিটি এস.আরের জন্য টাকার অংকে মাসিক লক্ষ্যমাত্রা এবং সুনির্দিষ্ট পণ্যের জন্য পিসভিত্তিক কোটা নির্ধারণ ও অর্জনের শতাংশ (%)।
7. **Official A4 Printable Invoice**: প্রতিষ্ঠানের নাম, লোগো, চালান বিবরণ, কথায় টাকা (টাকায় কথায়), **গ্রাহক / ডিলার স্বাক্ষর বক্স** এবং **কোম্পানি চেয়ারম্যান স্বাক্ষর সিল বক্স** সহ প্রফেশনাল লেআউট।
8. **Admin Feature Lock/Unlock**: যেকোনো মডিউল (চালান, স্টক, রিপোর্ট, টার্গেট) অ্যাডমিন প্যানেল থেকে যেকোনো সময় লক বা আনলক করার সুযোগ।
9. **Full Offline Backup & Restore**: একক ক্লিকে সমস্ত ডাটাবেজ JSON ফাইলে ডাউনলোড ও রিস্টোর।

## 💻 ৩. Local Installation & Development (ইনস্টলেশন ও রান করার নিয়ম)

প্রজেক্টটি আপনার কম্পিউটারে রান করতে:

```bash
# ১. গিট ক্লোন বা প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd probhati-erp

# ২. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে চালু হবে: `http://localhost:3000`

প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```

## 📱 ৪. Free Android APK / AAB Build Guide (অ্যান্ড্রয়েড অ্যাপ তৈরি)

কোনো পেইড সফটওয়্যার ছাড়াই বিনামূল্যে Android APK তৈরি করার ২টি সহজ উপায় রয়েছে:

### পদ্ধতি ১: GitHub Actions দিয়ে সম্পূর্ণ ফ্রি ও অটোমেটিক APK তৈরি (সবচেয়ে সহজ)
১. সম্পূর্ণ প্রজেক্টটি আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরিতে `git push` করুন।
২. রিপোজিটরিতে `.github/workflows/build-apk.yml` ফাইলটি ইতিমধ্যে অন্তর্ভুক্ত রয়েছে।
৩. GitHub-এ কোড পুশ করার সাথে সাথে GitHub Actions স্বয়ংক্রিয়ভাবে ক্লাউডে Android SDK ও Gradle দিয়ে APK বিল্ড করবে।
৪. আপনার GitHub রিপোজিটরির **Actions** ট্যাবে যান -> সর্বশেষ রান হওয়া বিল্ডে ক্লিক করুন -> **Artifacts** সেকশন থেকে `Probhati-ERP-Android-APK` ডাউনলোড করে সরাসরি যেকোনো অ্যান্ড্রয়েড ফোনে ইনস্টল করুন!

### পদ্ধতি ২: Android Studio / Capacitor দিয়ে আপনার কম্পিউটারে বিল্ড করা
১. বিল্ড ফাইল প্রস্তুত করুন:
```bash
npm run build
```
২. ক্যাপাসিটর অ্যান্ড্রয়েড প্ল্যাটফর্ম ইনস্টল ও সিঙ্ক করুন:
```bash
npm install -D @capacitor/cli @capacitor/core @capacitor/android
npx cap add android
npx cap sync android
```
৩. অ্যান্ড্রয়েড স্টুডিও ওপেন করুন:
```bash
npx cap open android
```
৪. Android Studio মেনু থেকে: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)** চাপুন। কয়েক মিনিটের মধ্যে আপনার `app-debug.apk` বা রিলিজ `app-release.apk` তৈরি হয়ে যাবে।

## 🗄️ ৫. Database Architecture & Schema (ডাটাবেজ আর্কিটেকচার)

ডাটাবেজে নিচের আলাদা কিন্তু সম্পর্কিত টেবিল/মডেলসমূহ ব্যবহৃত হয়েছে:
- `Admin`: অ্যাডমিনের তথ্য ও হ্যাশকৃত পাসওয়ার্ড
- `CompanySettings`: কোম্পানির নাম, চেয়ারম্যানের নাম, ঠিকানা, চালান প্রিফিক্স ও ডিফল্ট ছাড়
- `Products`: পণ্যের কোড, কার্টুনে পিসের সংখ্যা, T.P, ডিফল্ট %, D.P, মিনিমাম স্টক অ্যালার্ট, বর্তমান স্টক
- `Dealers`: ডিলারের কোড, নাম, মোবাইল, রুট, পূর্বের বকেয়া ও বর্তমান বকেয়া
- `SR`: এস.আরের কোড, নাম, মোবাইল, রুট, মাসিক টার্গেট ও পণ্যভিত্তিক কোটা
- `Invoices`: চালান নম্বর, তারিখ, ডিলার/এস.আর আইডি, মোট কার্টুন, মোট পিস, গ্রস টাকা, ছাড়, নিট প্রদেয়, পরিশোধ ও বকেয়া
- `InvoiceItems`: পণ্যের নাম, কার্টুন, পিস, মোট পিস, T.P, %, D.P, লাইন টোটাল, ড্যামেজ ও রিটার্ন
- `Purchases`: ফ্যাক্টরি পারচেজ তারিখ, সাপ্লায়ার নাম, পণ্যের বিবরণ, মোট কার্টুন, মোট পিস ও ক্রয়মূল্য (স্টক বৃদ্ধির উৎস)
- `DamageRecords`: ক্ষতিগ্রস্ত পণ্যের তারিখ, পণ্যের নাম, কার্টুন, পিস, কারণ ও এস.আর নাম
- `ReturnRecords`: গ্রাহক থেকে ফেরত পণ্যের তারিখ, পণ্যের নাম, কার্টুন, পিস, কারণ ও ডিলারের নাম
- `StockAdjustments`: অডিটজনিত স্টক যোগ/বিয়োগের অডিট লগ
- `FeatureLocks`: ডিলার চালান, এস.আর চালান, স্টক, পারচেজ, ড্যামেজ, টার্গেট ও রিপোর্টের লক স্ট্যাটাস

## 🔄 ৬. Backup & Restore Guide (ডাটা ব্যাকআপ ও পুনরুদ্ধার)

১. মেনু থেকে **"ব্যাকআপ ও রিস্টোর"** বাটনে যান।
২. **"ব্যাকআপ ডাউনলোড করুন"** চাপলে তাৎক্ষণিকভাবে সম্পূর্ণ ডাটাবেজ একটি `.json` ফাইল হিসেবে আপনার কম্পিউটারে বা ফোনে সেভ হবে।
৩. ফোন পরিবর্তন করলে বা ডাটা রিস্টোর করতে চাইলে **"ব্যাকআপ ফাইল সিলেক্ট করুন"** দিয়ে পূর্বে সংরক্ষিত ফাইলটি নির্বাচন করলেই সব ডাটা আবার লাইভ হয়ে যাবে।

## 🔒 ৭. Feature Lock/Unlock Guide (ফিচার লক/আনলক)

অ্যাডমিন চাইলে যেকোনো সংবেদনশীল মডিউল কর্মীদের অপব্যবহার রোধে লক করে রাখতে পারেন:
১. **"সেটিংস ও ফিচার লক"** পেজে যান।
২. যেকোনো ফিচারের পাশের 🔓 আইকনে ক্লিক করে 🔒 লক করতে পারবেন।
৩. লক থাকা অবস্থায় কোনো ইউজার উক্ত ফিচার ওপেন করলে **"This feature is currently locked by Admin."** বার্তা দেখতে পাবেন।
৪. অ্যাডমিন অ্যাকাউন্টে লগইন থাকা অবস্থায় ওখান থেকেই সরাসরি "Unlock This Feature Now" চাপ দিয়ে পুনরায় চালু করা যায়।
